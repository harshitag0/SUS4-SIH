# Logistics & traceability
- Lot code (QR) on every crate/pallet: farmer(s), plot, harvest date, grade, certificate hashes.
- Cold chain: temperature logger readings attached to the lot; a breach raises an alert and an insurance trigger.
- Export checklist: APEDA registration, packhouse approval, phytosanitary certificate, VHT/irradiation certificate, airway bill, Singapore import requirements.
- Handover scans: farm -> FPO packhouse -> airport -> buyer. Each scan appends to the lot's hash chain.

Status: spec only.
